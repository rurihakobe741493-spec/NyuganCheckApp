# Nyugan Check App

乳がんについて、気になる変化があるときや、検診を受けるか迷っているときに、次にとるとよい行動を案内する Web アプリです。

公開先: **https://nyugancheckapp.onrender.com/**

---

## このアプリの目的

乳がんに関する情報は公的機関が数多く公開していますが、「自分は今どうすればいいのか」に答えてくれるものは多くありません。年齢、症状の有無、家族歴によって、行き先は乳腺外科であったり、自治体の検診であったり、遺伝性腫瘍のカウンセリングであったりします。

このアプリは、最大3つの質問に答えると、その人の状況に合った次の行動を示します。あわせて、検診の受け方や当日の流れについての Q&A を用意しています。

### このアプリがやらないこと

- **診断はしません。** このアプリが行うのは、適切な相談先への振り分けです。結果は医師の判断に代わるものではありません。
- **検査結果の解釈はしません。** 受け取った結果について不安がある場合は、検査を受けた施設に問い合わせてください。
- **しこりの探し方といった手技は扱いません。** 推奨されているのはブレスト・アウェアネス（自分の乳房の状態に日頃から関心を持ち、いつもと違う変化に気づいたら医療機関へ相談する）という考え方であり、決まった手順の実施ではないためです。

気になる症状がある場合は、このアプリの結果にかかわらず医療機関を受診してください。

## 内容の根拠

本文は、以下の一次情報をもとに構成しています。

- [がん情報サービス](https://ganjoho.jp/)（国立がん研究センター）
- [日本乳癌学会](https://www.jbcs.gr.jp/) 乳癌診療ガイドライン
- [日本遺伝性乳癌卵巣癌総合診療制度機構（JOHBOC）](https://johboc.jp/)
- 厚生労働省「がん予防重点健康教育及びがん検診実施のための指針」

方針として、次の点を守っています。

- 各項目は情報の提示で終わらせず、「だから受診する / 相談する」という行動で閉じる
- 対策型検診として推奨されているかどうかと、精密検査で標準的に用いられるかどうかを書き分ける（超音波検査など、両者が一致しない検査があるため）
- 断定的な表現を避け、同時に、不安によって行動を促すことをしない

統計の数値は出典の更新に追従する必要があります。「既知の制約」を参照してください。

## 設計上の判断

### Q&A を DB ではなく YAML で持つ

Q&A の内容は `config/qa.yml` に置き、`QaItem` というプレーンな Ruby オブジェクトから読み込んでいます。

この内容を書き換えるのは編集者だけで、利用者が投稿することはありません。DB に載せると、マイグレーション、seed、レビューのための管理画面と認証が必要になりますが、得られるものがありません。YAML であれば変更履歴は Git が持ち、差分をそのままレビューできます。医療に関する記述を扱う以上、「いつ、何を、なぜ変えたか」が追える形であることを優先しました。

### 施設検索は外部リンク方式

検診施設や専門医の一覧を自前のデータとして保持するには、公開元の許諾が必要です。無断で複製すれば、出典の管理が及ばないデータを再配布することになります。

そのため一覧は持たず、目的別に公式の検索ページへ案内する方式にしました。データの正確さと鮮度は公開元に委ねられ、施設の開廃業への追従も不要になります。乳がん検診の施設検索に関しては、乳房健康研究会のホームページ（のトップページ）が許諾不要だったため、リンクしています。

導線は次の3つに分けています。

1. 症状がある → 乳腺外科を標榜する医療機関
2. 症状がない → マンモグラフィ検診の認定施設
3. 家族歴が気になる → 遺伝性乳がん卵巣がんのカウンセリング

この分岐は `FacilitiesController` の `PURPOSES` ホワイトリストで管理しています。値を追加する際は、対応するパーシャルを同時に作ることが前提です。想定外の値でテンプレートを探しにいくことがないようにするためです。

### アコーディオンに JavaScript を使わない

Q&A の開閉は `<details>` / `<summary>` で実装しています。デザインツールが出力した案には JavaScript による実装が含まれていましたが、移植していません。

ネイティブ要素は JS の読み込み完了前から動作し、キーボード操作とスクリーンリーダーへの対応が最初から入っています。ブラウザのページ内検索が閉じた項目にも到達します。矢印の回転は `group-open:` を使い、CSS だけで処理しています。

同様の理由で、`focus:outline-none` は移植していません。キーボードで操作したときに現在位置が分からなくなるためです。

### Tailwind v4 の `@theme` に集約

デザインツールが出力したのは v3 形式の `tailwind.config` でしたが、設定は `application.tailwind.css` の `@theme` に移しています。フォントは全て同一のため個別のユーティリティクラスを廃して `--font-sans` に一本化し、余白は全て 4px の倍数だったため数値クラスに置換しました。

## 既知の制約

- **モバイル幅でグローバルナビゲーションが表示されません。** `md` 未満でナビが隠れ、ハンバーガーメニューがありません。検索エンジンから `/qa` へ直接来た場合、他の画面への導線がない状態です。対応予定です。
- 施設検索は外部サイトへ案内する方式のため、アプリ内で施設名や所在地を検索することはできません。
- がん統計は年に数回更新されます。本文中の数値は記載時点のもので、出典の更新に追従する運用が必要です。
- デプロイは Render の手動デプロイです。`main` への push だけでは公開内容は変わりません。

## Issue について

このリポジトリの Issue は、不具合の報告や技術的な指摘のためのものです。

**個別の症状や受診についてのご相談は受け付けていません。** 気になる症状がある場合は、医療機関を受診してください。

本文の内容について、出典との相違や記述の誤りにお気づきの場合は、該当箇所と根拠を添えてお知らせいただけると助かります。
